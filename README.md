# 🎮 Игра "Тетрис" (Tetris) на Pygame

Динамичная 2D-игра написанная на Python с использованием библиотеки Pygame.

## 🚀 Механика игры

- **Игрок**: Управляет блоками с помощью клавиш (`D-Вправо`, `S-Вниз`, `A-Влево`, `W-Поворот`) 
  также есть вспомогательные клавишы (`Пробел-Сброс блока вниз`, `P-Пауза`).
- **Цель**: Создать ровные линии чтобы набрать больше очков.

## 🛠 Технологии

- Python 3
- Pygame-ce

## 💻 Как запустить проект

1. **Скачайте** весь проект
2. **Найдите** файл Tetris.exe
3. **Запустите** найденный файл
